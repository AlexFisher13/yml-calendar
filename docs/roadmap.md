# Дорожная карта

Дорожная карта описывает последовательность результатов. Конкретные задачи
ведутся в `backlog.md`.

## Этап 0 — фундамент

- Зафиксировать видение, архитектуру и инженерные правила.
- Создать каркас монорепозитория.
- Определить первый REST API-контракт.
- Согласовать модель дат, времени и повторений.

## Этап 1 — локальный MVP

- Создать компактный Go backend.
- Создать React frontend.
- Поднять PostgreSQL через Docker Compose.
- Добавить встроенные SQL-миграции и первую схему данных.
- Реализовать создание, чтение, изменение и удаление календарей и событий.
- Перенести многомесячное представление из прототипа.
- Реализовать импорт текущего YAML.

## Этап 2 — безопасный доступ

- Добавить регистрацию и вход.
- Разграничить доступ к календарям.
- Добавить валидацию, аудит ошибок и базовые ограничения API.
- Покрыть основные сценарии unit- и integration-тестами.

## Этап 3 — первый production

- Подготовить VPS.
- Настроить systemd, Caddy и HTTPS на production VPS.
- Публиковать образы в GitHub Container Registry.
- Настроить CI и подтверждаемый CD через GitHub Environment.
- Настроить backup, restore, healthcheck и rollback.

## Этап 4 — удобное веб-приложение

- Сделать адаптивный интерфейс.
- Добавить PWA-манифест и offline shell.
- Реализовать напоминания и повторяющиеся события.
- Добавить экспорт в YAML и ICS.
- Улучшить доступность и мобильное управление.

## Этап 5 — совместное использование

- Добавить приглашения в календарь.
- Добавить роли владельца, редактора и читателя.
- Добавить участников событий.
- Добавить безопасные публичные ссылки при наличии продуктовой необходимости.

## Этап 6 — iPhone

- Проверить востребованность сценариев, ограниченных PWA.
- Создать SwiftUI-клиент для существующего REST API.
- Добавить push-уведомления и системную интеграцию.
- Рассмотреть виджеты и интеграцию с системным календарём.
