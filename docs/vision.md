# Видение проекта

## Зачем существует проект

Проект создаёт персональный календарь, которым удобно пользоваться в браузере,
на телефоне и в будущем в нативном приложении для iPhone.

Текущий YAML-календарь доказал полезность непрерывного многомесячного
представления, праздников, рабочих выходных и простого списка событий. Следующий
этап превращает этот прототип в приложение с постоянным хранением,
синхронизацией и безопасным доступом с разных устройств.

## Для кого

Первая версия предназначена для владельца проекта и небольшого числа
приглашённых пользователей. Массовый публичный сервис не является целью
первого этапа.

## Основная ценность

- Единое представление личных событий на разных устройствах.
- Быстрый обзор нескольких месяцев без переключения между экранами.
- Корректная работа с праздниками, переносами выходных и часовыми поясами.
- Контроль над данными и возможность их экспортировать.
- Постепенное развитие без зависимости от конкретного клиентского приложения.

## Продуктовые принципы

- Простота важнее количества функций.
- Данные пользователя принадлежат пользователю и должны экспортироваться.
- Веб-версия является первым полноценным клиентом.
- PWA появляется раньше отдельного iPhone-приложения.
- Backend и API проектируются сразу для нескольких клиентов.
- Существующий YAML поддерживается как формат импорта, но не как основное
  хранилище.

## Не входит в первую версию

- Микросервисная архитектура.
- Публичный маркетплейс календарей.
- Корпоративное управление организациями.
- Полная замена Google Calendar или Apple Calendar.
- Нативные приложения для всех платформ одновременно.

## Признаки успеха первой версии

- Пользователь может войти с компьютера и телефона и увидеть одинаковые данные.
- Событие можно безопасно создать, изменить и удалить.
- Календарь корректно отображает события на весь день и события со временем.
- Существующие YAML-данные импортируются без ручного переноса.
- Приложение восстанавливается из проверенной резервной копии.
